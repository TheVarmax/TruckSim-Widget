### 🚀 Brand-New Installer & Updater
* **Modern Setup Wizard**: Replaced the legacy installer with a fresh, lightweight, and reliable setup wizard.
* **Zero-Hassle Game Detection**: Automatically detects your ETS2 and ATS installations and configures telemetry plugins with zero hassle.
* **Safe Updates**: Reinstalling or updating preserves your settings, trip history, and license state.
* **Seamless Background Updates**: New versions install in the background and relaunch automatically.
* **Reliable Update Checks**: Fixed an issue where checking for updates could fail with an unexpected connection error.
* **Safer Recovery**: If installation is interrupted, the setup wizard restores backed-up files before another install or uninstall begins. It stops if recovery cannot complete.

### 🎨 Visual & Appearance Improvements
* **Consistent Transparency**: The opacity slider now applies smoothly across all parts of the widget, including icons, route details, and status indicators.
* **Smooth Startup Animation**: Fixed a visual glitch where backgrounds appeared fully solid for a moment during launch before applying your transparency. Elements now fade in smoothly from the start.

### 🔄 Telemetry & Status Synchronization
* **Delivery Progress Survives Restarts**: The distance covered and maximum speed of an active delivery are restored after restarting the game or widget, including in ATS.
* **Reliable Trip Recovery**: Active deliveries can be restored from their individual save files when the main state file is missing or damaged.
* **Instant Reset on Game Exit**: Trip and route values clear from the screen together when you quit the game or exit to the menu. An active delivery is restored when you return.
* **No More False TrucksBook Errors**: Leaving the game or switching profiles will no longer briefly flash a false TrucksBook error.

### ⚡ Performance & Resource Optimization
* **Lighter on Your System**: Greatly reduced CPU and disk usage when monitoring delivery progress and TrucksBook status.
* **Smoother Overlay**: Background telemetry tracking runs much more efficiently with minimal resource overhead.

### 🛡️ Stability & Reliability
* **Data Corruption Protection**: Your settings, logbook, and active trip history are protected against accidental corruption during crashes or power cuts.
* **Safer Diagnostics**: A failure to write the application log no longer crashes the widget.
* **Window & Dragging Fixes**: Fixed rare crashes when rapidly moving the overlay or closing the application.
* **Settings & Export Fixes**: Improved trip logbook export and fixed minor glitches in the settings menu.
